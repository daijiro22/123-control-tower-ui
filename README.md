# 123-control-tower-ui

個人用ツール「司令塔」の状況ボード（Claude の会話の中に出るウィジェット）の表示部品と、案内役のキャラクター「トウ」の絵です。

- `board.js` … ボードを描く部品。ウィジェットの中の `#cx-data`（JSON）を読み、`#cx-root` に描きます。データはこのリポジトリに含みません。
- `tou/*.webp` … トウの表情 9 種（にっこり・呼びかけ・しんぱい・考え中・すやすや・話す・手を振る・出発・跳ねる）。Codex の画像生成で作りました。

ウィジェットは決まった配信元からしかスクリプトや画像を読めないため、jsdelivr 経由（`https://cdn.jsdelivr.net/gh/daijiro22/123-control-tower-ui@<タグ>/`）で読み込みます。更新するときは新しいタグを打ち、司令塔の雛形のタグを差し替えます。

元の作業場所は非公開のリポジトリ（`123_control-tower/design/`）で、このリポジトリは `build_public.py` の出力です。
